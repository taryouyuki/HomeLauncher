# HomeLauncher

Kotlin + Jetpack Compose + Material 3(Dynamic Color)で作った Android ホームランチャーです。
アイコンはピンクのログハウス(Adaptive Icon / Vector Drawable)。

- minSdk 26 / targetSdk・compileSdk 36
- パッケージ名: `jp.achi.homelauncher`
- 設定値はすべて端末内に永続化(SharedPreferences + JSON)

## 1. GitHub でビルドして APK を作る(いちばん簡単)

1. GitHub で新規リポジトリ `HomeLauncher` を作成(空のまま)。
2. ZIP を展開し、`HomeLauncher/` の中身をそのまま push します。

   ```bash
   cd HomeLauncher
   git init
   git add .
   git commit -m "Initial commit"
   git branch -M main
   git remote add origin https://github.com/<ユーザー名>/HomeLauncher.git
   git push -u origin main
   ```

   `app/release.keystore`(署名鍵)も一緒に push してください(後述)。
3. push すると GitHub Actions(`.github/workflows/build.yml`)が自動で走ります。
   手動実行は Actions タブ → Build APK → Run workflow。
4. 完了後、実行結果ページ下部の Artifacts から `HomeLauncher-apk` をダウンロードし、
   中の `app-release.apk` をスマホにインストールします(提供元不明アプリの許可が必要)。
5. 初回起動後、ホームボタンを押して「HomeLauncher」を選び「常に」にするか、
   アプリ内 設定 → 「デフォルトのホームアプリに設定」から変更します。

## 2. ローカルでビルドする

JDK 17 以上と Android SDK(compileSdk 36)が必要です。Android Studio で `HomeLauncher/` を開くだけでも構いません。

```bash
./gradlew testDebugUnitTest      # 単体テスト
./gradlew assembleRelease        # app/build/outputs/apk/release/app-release.apk
```

## 3. 署名とアップデート(再インストール不要にする)

Android は「署名が同じ」かつ「versionCode が大きい」APK なら、アンインストールせず上書き更新できます。

- 署名鍵は `app/release.keystore` をリポジトリに同梱しています。
  - ストアパスワード / キー別名 / キーパスワード: `homelauncher` / `homelauncher` / `homelauncher`
  - debug ビルドも同じ鍵で署名するので、debug と release も上書きできます。
- **この鍵を変えると別アプリ扱いになり、更新できなくなります。** 変更・削除しないでください。
- versionCode は GitHub Actions の実行番号(`run_number`)が自動で入ります。ビルドするたびに増えます。
  ローカルビルドでは `VERSION_CODE=10 ./gradlew assembleRelease` または
  `./gradlew assembleRelease -PVERSION_CODE=10` で指定します(未指定は 1)。
  **GitHub 版のあとにローカル版を入れる場合は、GitHub 側の番号より大きい値を指定してください。**
- 表示用のバージョン名は `app/build.gradle.kts` の `appVersionName` を編集します。

### 自分専用の鍵に差し替えたい場合(公開リポジトリ向け)

同梱の鍵はパスワードが公開されているため、リポジトリを公開する場合は自分の鍵に差し替えるのを推奨します。
**ただし差し替えると署名が変わるため、一度アンインストールが必要です。**

```bash
keytool -genkeypair -keystore my.keystore -alias mykey -keyalg RSA -keysize 2048 -validity 10000
base64 -w0 my.keystore    # この出力を Secret に登録
```

GitHub の Settings → Secrets and variables → Actions に次を登録します。

| Secret | 内容 |
|---|---|
| `KEYSTORE_BASE64` | keystore を base64 にした文字列 |
| `KEYSTORE_PASSWORD` | ストアパスワード |
| `KEY_ALIAS` | キー別名 |
| `KEY_PASSWORD` | キーパスワード |

Secrets があれば workflow が自動でそちらを使います。以後はその鍵を絶対に失くさないでください。

## 4. 使い方

| 操作 | 方法 |
|---|---|
| アプリ一覧を開く | ホームで下から上へスワイプ(閉じるのは上部つまみを下へ / 戻る) |
| 並び替え | 一覧上部のチップ(名前順 / 最終起動順 / ダウンロード順 / よく使う順 / 更新順)。並び基準の値(日時・回数)がアイコン下に表示される |
| 部分一致検索 | 一覧の検索欄、またはホームの検索バー |
| Web 検索 | ホームの検索バーに入力して検索キー(URL は設定で変更可) |
| ホームにアプリ追加 | 一覧でアイコン長押し → ホーム画面に追加 / ホーム空き地を長押し → アプリをホームに追加(**長押しした場所**に配置)。ブラウザ等の「ホーム画面に追加」にも対応(本ランチャーを既定のホームにしている場合。追加先はホームの最初の空きマスで、追加時にページ番号を表示) |
| 移動・リサイズ | アイコン・フォルダ・検索バー・メディアバーは長押し、ウィジェットも長押しで編集モード(右上のボタンは「削除」)。本体をドラッグで移動、右下の丸をドラッグでリサイズ(離すとマスにスナップ)。上部バーの「詳細」で数値指定。ドラッグ中に画面端で少し待つと**隣のページへ移動**できる。アイコンを別のアプリ/フォルダに重ねて離すと**フォルダ作成・追加** |
| 重なった時 | 移動・追加先に既存アイテムがあると通知して重ねる。設定 → ホームで「重ねる / 既存を下へずらす / 既存を上へずらす」を選択可 |
| ウィジェット追加 | ホームの空き地を長押し → ウィジェットを追加(アプリのアイコン付き。アプリ名・ウィジェット名で検索) |
| ウィジェットスタック | 空き地長押し → ウィジェットスタックを作成 → 編集モードの「スタック管理」で複数追加。その領域を左右スワイプで切り替え |
| フォルダ | 空き地長押し → フォルダを作成。一覧の長押し「フォルダに追加」/ 編集モードの「フォルダへ」でアプリを入れる。ドックの「+」からも作成可 |
| 編集モード | 長押しで入る。編集中はウィジェット・アイコンは開かず、タップで選択だけ(長押しの指を離しても開かない) |
| 編集モード(長押し不要) | ホーム右下の「✎」ボタン、または空き地長押しメニューで入る。編集中はアイコン・ウィジェットをタップしても開かず選択だけ。空き地タップでその場所に追加。「✓」か「完了」で終了(従来の長押し編集も使える) |
| 押し出し並び替え | 設定 → ホーム → 「押し出し」。アイコンを別のアイコンの位置へ置くと、そこから後ろが1つずつずれる(A B C で C を先頭へ → C A B)。ドックは常にこの動作 |
| ドックの並び替え | ドックのアイコンを長押ししたまま左右へ動かす。動かさず離すとメニュー |
| 幅いっぱいに | ウィジェット/スタックを編集モードで選び「幅いっぱいに」(スタックは中の全ウィジェットの縦横比から高さを決定) |
| スタックの並び替え | 「スタック管理」の ↑ ↓ |
| 自動調整 | 設定 →ホーム →「すべて/ウィジェットのみ/アプリアイコンのみ」、またはホーム空き地長押しメニュー |
| 仕事用アプリ | アプリ一覧の「仕事用」チップ(Island など仕事用プロファイルのアプリ。タップで起動。ホームへの追加は未対応) |
| 自由配置 | 設定 → ホーム →「自由配置モード」。ONの間はマスに縛られず位置・サイズを自由に変更(OFFで動かすとマスに戻る) |
| ウィジェット内スクロール | メモ帳など中身が縦に動くウィジェットは、縦ドラッグをウィジェットが優先(アプリ一覧は開かない)。横スワイプはページ/スタック切替 |
| ウィジェット→スタック | 編集モードの「スタックに変換」(同じ場所・大きさのスタックの1枚目になる)。スタックは最後の次で最初に戻る |
| ダブルタップ | 編集モードの「ダブルタップ設定」で、他のアプリ本体またはそのアプリのショートカットを割り当て(ショートカット取得はデフォルトのホームのとき) |
| 通知バッジ | 通知アクセスを許可すると件数を表示。バッジ付きアプリを長押し →「通知を見る」(タップで開く/「消す」) |
| アイコンの形 | 設定 → ホーム: そのまま/丸/丸みの四角/角丸/歪んだ丸/花形/五角形/六角形/八角形/ハート |
| 画面を更新 | ホーム空き地の長押し →「画面を更新」(アプリ一覧・ウィジェット・メディア・通知を取り直す) |
| フォント | 設定 → 色・外観 → フォントを追加(ttf/otf)。標準に戻すも可 |
| 検索 | ひらがなで、カタカナや一部の漢字(電話・設定・天気など)のアプリ名にも一致。一覧で長押し →「読み仮名を設定」で任意のアプリに登録可 |
| メディアバー | 小さくすると自動で簡略化(極小=再生のみ、小=3ボタン、通常=曲名付き) |
| ドック | 左右スワイプでページ切り替え(最後の次は先頭に戻るループ、設定でON/OFF)。縦幅・アイコン透明度は設定で変更 |
| 設定画面 | タブ(ホーム / ドック / ウィジェット・バー / アプリ一覧 / 色・外観 / その他)と、上部のプレビュー(ホーム・一覧の切替) |
| 色 | 設定画面の配色(Dynamic Color / ダーク)とは別に、ホーム画面・一覧の色を「好きな色」で指定可(例: ピンク) |
| アプリ一覧の背景 | 設定 → アプリ一覧(テーマ色 / 好きな色 + 透明度) |
| ウィジェットのスクロール | ウィジェット上の縦スクロール中は一覧を開かない |
| 検索バー・メディアバーの追加/削除 | 空き地長押しメニューで追加、編集モードの「削除」で削除。透明度は設定 → ウィジェット・バー |
| 不透明度 | 設定でウィジェット全体・アイコン全体、「詳細」で個別に設定 |
| アイコンサイズ変更 | 設定 → ホーム画面 / アプリ一覧 |
| メディア操作 | メディアバー(⏮ ▶/⏸ ⏭)。曲名表示は通知アクセスの許可が必要 |
| バックアップ / 復元 | 設定 → バックアップ・復元(JSON) |

### バックアップについて
設定・ホームのアイコン配置・ドック・起動回数を JSON で保存/復元します。
ウィジェットの ID は端末ごとに発行されるため、復元後に「ウィジェットの再追加」ダイアログが出ます。
配置・サイズ・透明度は保持され、再追加時に再度許可が求められます。

## 5. テスト

### 自動テスト(`./gradlew testDebugUnitTest`)
- `AppSorterTest`: 名前順・最終起動順・ダウンロード順・よく使う順・更新順と部分一致検索
- `BackupCodecTest`: バックアップの書き出し→読み込み、不正データの拒否、範囲外値の補正
- `KanaTest`: ひらがな検索(カタカナ・漢字・読み仮名)
- `GridLogicTest`: 自由配置・自動整列、 重なりポリシー(重ねる/下へ/上へ)、ホームの空きセル探索、ウィジェットの占有、スタック子の除外、グリッド縮小時の補正
- フォルダ・スタック・検索/メディアバーのバックアップ往復も `BackupCodecTest` で確認

### 手動テスト手順
1. インストールして起動 → ホームとドックが表示される。
2. ホームを下から上へスワイプ → アプリ一覧が開く。
3. 並び順チップを切り替える。アプリを起動したあと「最終起動順」で直近のものが先頭、「よく使う順」で回数順になる。
4. 検索欄に名前の一部を入力 → 部分一致で絞り込まれる。
5. 設定 → アイコンサイズを動かす → ホーム/一覧に即反映。
6. ホーム空き地を長押し → ウィジェットを追加 → 「⋮」から幅・高さ・不透明度を変更 → 再起動しても保持される。
7. 設定 → 書き出し → 設定を変更 → 復元 → 元に戻る。ウィジェット再追加ダイアログが出る。
8. 通知アクセスを許可し、音楽アプリで再生 → パネルに曲名が出て ⏮ ▶/⏸ ⏭ が動く。
9. 設定 → デフォルトのホームアプリに設定 → ホームボタンで HomeLauncher が起動する。
10. 新しい APK を上書きインストール → 再インストール不要で更新できる(署名固定・versionCode 増加)。

- 設定の JSON バックアップ/復元
- Dynamic Color(Android 12+)、ライト/ダーク/システム切替
- 署名固定、GitHub Actions、単体テスト
- 長押し位置への追加、重なり時の通知とずらし、アイコン重ねでフォルダ化、ページ跨ぎドラッグ、タブ式設定+プレビュー、好きな色のホーム配色、バー/ドック透明度・ドック縦幅・ループ、一覧背景、ホーム画面に追加(ピン留め)
- ピンクのログハウスの Adaptive Icon(テーマアイコン対応)

- アイコンセット(ホームの空き地を長押し →「アイコンセットを作成」。枠のマス数ぶんが1ページ、スワイプで切替・最後→最初へ。重ねてドロップでも追加)
- ウィジェット/スタック単位の透明度(選択 → 上部バー「透明度」)
- アプリ一覧のカテゴリー順(自動仕分け+長押しで手動変更)
- 整列: アイコンのみ / ウィジェットのみ(ホームのメニュー・設定)
- ホームのループ・メインページ指定・周りの余白、アプリ名2行、テーマアイコン設定、アイコンサイズ統一
- かわいいテーマ5種、設定内検索、検索履歴、メディアの再生元/出力先表示、ドックのダブルタップ設定
- フォントはすべての文字(アプリ名・メディアバー等)に反映

- クイックパネル(ホームで上から下へスワイプ): Twitter(X)/Discord/Spotify等の通知とメディア操作を、アプリを開かずに確認(通知アクセス方式。ログイン連携ではない)
- おまかせ微調整(すべて/ウィジェット/アイコン)と「調整前/調整後」切替・確定
- ダブルタップ解除・スタック解除・アイコンセット解除、フォルダの1行の数(3〜5)、ドックのサイズ上限拡大

- アイコンセット内のアイコンもダブルタップ設定可(セット管理から)、自由配置を「ウィジェットのみ」にできる設定
- アプリ名2行でもアイコン位置がそろう、形: ゆるい丸・ふっくらハート
- クイックパネル: 並び替え(↑↓)、通知の履歴保持とクリア、通知からの返信(返信に対応した通知のみ)、メディアボタンを図形描画に変更
- ショートカットもフォルダに入れられる(重ねるとフォルダ化。設定でON/OFF)
- 便利機能: アプリ一覧から隠す(「非表示」チップで再表示)、ホームのアプリ選択 →「ショートカット・情報」メニュー

- 省電力: 通知の集計をまとめて1回に(連続通知でのCPU・電池消費を削減)、クイックパネルの履歴は開いているときだけ監視
- フォルダ背景の色・不透明度、ドックのページ数指定、アプリ一覧の最下部に「ランチャーの設定を開く」、クイックパネルの「編集」ボタン
- アイコンのフォルダ化は、重なり面積(自由配置にも対応)で判定

- アイコンセットにショートカット/フォルダも入れられる(重ねてドロップ、またはセット管理から)
- 「アプリ一覧」「クイックパネル」を開くアイコンをホームに置ける(空き地メニュー。移動・削除可)
- ドック: 長押しメニューに「左へ移動/右へ移動」、アイコンサイズはドック高さに縛られず自動で広がる
- フォルダ内のアプリ/ショートカットもダブルタップ設定可

- ホーム長押しメニューを「追加する / 整列・自動調整 / その他」に整理(ランチャー設定は最上段)。ショートカットだけを置ける
- ドック: 移動メニューは続けて動かせる、「ここにアプリを追加」は差し込み(既存は右へずれる)
- アプリ一覧: 「システム」チップ、システムアプリは自動で「システム」カテゴリー

- アプリのアイコンを好きな画像に変更(ホームで選択→「アイコン変更」/アプリ一覧の長押し)
- ジェスチャー割り当て(上/下スワイプ、何もない所のダブルタップ → アプリ一覧・クイックパネル・検索・設定・編集モード・任意のアプリ)
- アプリ一覧の絞り込み(最近入れた/よく使う/未使用)
- 項目を選択中はページのスワイプを止める(ウィジェットを左右に動かすとき横取りされない)、編集終了時に画面を自動更新

## 7. 注意
- 検出済みの制約: ウィジェットは「⋮」ボタンから編集します(ウィジェット自体の長押しは各ウィジェットが処理するため)。
- 通知アクセスは曲名表示のためだけに使い、通知の内容は読み取りません。
- 初版は作成環境から Android 用の依存ライブラリを取得できなかったため、ローカルでのビルド・テスト実行は未確認です。最初の GitHub Actions 実行で確認してください。
